# SBTI 测试定制器 Skill

一个通用的 Skill，允许用户基于 GitHub 上的 SBTI 源码一键替换内容，支持在任何可以执行 Skill 的 IDE 或开发工具中使用。

## 项目结构

```
├── example/             # 示例配置和测试项目
│   ├── test-skill-configs/  # 小红书用户人格测试配置示例
│   └── test-skill-project/  # 测试项目（已替换内容）
├── sbti-customizer/     # 技能核心代码
│   ├── README.md        # 技能使用说明
│   ├── main.js          # 主脚本
│   ├── package.json      # 项目配置
│   └── skill.json        # 技能配置
└── .gitignore           # Git 忽略文件
```

## 功能特性

- **项目初始化**：自动从 GitHub 仓库克隆 SBTI 源码
- **维度系统替换**：自定义维度元数据、解释和顺序
- **题目系统替换**：自定义常规问题和特殊问题
- **人格系统替换**：自定义人格信息和图片
- **匹配规则替换**：自定义人格匹配模式
- **验证与测试**：确保替换后的测试系统正常运行
- **部署配置**：提供本地部署和访问的指导

## 快速开始

1. **安装**：确保环境中安装了 Node.js，克隆本仓库到本地

2. **使用技能**：
   - 进入 `sbti-customizer` 目录
   - 按照 [sbti-customizer/README.md](sbti-customizer/README.md) 中的说明使用技能

3. **示例配置**：
   - 查看 `example/test-skill-configs/` 目录中的小红书用户人格测试配置示例
   - 这些配置可以作为您自定义测试的参考

## 示例配置

本项目包含一个完整的小红书用户人格测试配置示例：

- **维度系统**：15个维度，分为5个模型（内容创作、社交互动、消费习惯、审美偏好、生活方式）
- **题目系统**：32个题目（30个常规 + 2个特殊）
- **人格系统**：27个人格类型，包括种草达人、下单达人、平价达人等
- **匹配规则**：完整的人格匹配模式
